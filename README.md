Frontend Developer Portfolio

A multi-page portfolio website built with semantic HTML and CSS. This project showcases a simple personal portfolio structure containing a home page, projects page, articles page, and contact page.

A.Pages
-Home — Introduces the frontend developer profile, projects, work experience, education, and testimonials.
-Projects — Displays a collection of frontend development projects.
-Articles — Contains articles related to frontend development, HTML, CSS, JavaScript, and web development.
-Contact — Provides a contact form for visitors who want to send a message or collaborate.

B.Features

- Multi-page website structure
- Semantic HTML structure
- Consistent navigation across all pages
- Responsive layout for different screen sizes
- SEO-related meta tags on each page
- Contact form with multiple input fields
- Reusable CSS styles shared across the website
- Dark-themed interface with a purple accent color

C.Technologies

- HTML5
- CSS3

F.Navigation
The website uses a shared navigation menu that connects the main pages:

```text
Home
Projects
Articles
Contact
```

Each page contains the same navigation structure so visitors can move between pages easily.
